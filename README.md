# 🔧 MechMaster – Workshop Management Portal

## 📖 Overview

A web-based workshop management portal developed using ASP.NET MVC 5 and SQL Server. It helps manage customers, items, invoices, and users through a simple and responsive interface.

## 🚀 Features

- Customer Management
- Item Management
- Invoice Management
- User Management
- Login & Authentication
- Search and CRUD Operations
- Responsive and Modern UI

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript, Bootstrap, jQuery

**Backend:** C#, ASP.NET MVC 5, .NET Framework 4.7.2, ADO.NET

**Database:** SQL Server

**Tools:** Visual Studio, Git, GitHub
